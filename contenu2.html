Exemple de configuration

Boîtier : Moyen tour avec bonne ventilation, ~70€

Alimentation : 650W certifiée 80+ Bronze, ~80€

Carte mère : B550 (AMD) ou B660 (Intel), ~120€

Processeur : AMD Ryzen 5 5600 ou Intel Core i5-12400F, ~200€

Mémoire RAM : 16 Go DDR4 3200 MHz, ~60€

Stockage : SSD NVMe 500 Go pour le système + HDD 1 To pour le stockage, ~80€

Carte graphique : NVIDIA RTX 3060 ou AMD RX 6600, ~350€

Refroidissement : Ventirad inclus ou refroidissement supplémentaire si overclock, ~30€


Total : ~990€

Cette configuration permet de jouer en 1080p à fond sur presque tous les jeux et fait tourner des logiciels de création (Photoshop, montage vidéo) sans problème.
